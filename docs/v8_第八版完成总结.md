## 1. 第八版要解决什么问题？

v1～v7 用精简前端证明了后端主链路。v8 把产品观感拉到原仓水准，并让存储可上云：

1. **迁入原仓前端**：Landing / Auth / Create / Candidates / Editor 工作台布局与组件。  
2. **接口对齐**：本仓已有能力（会话、工具、Agent、生图、选区、图层、SSE、导出）与原仓 API 契约兼容。  
3. **腾讯云 COS**：默认 `STORAGE_BACKEND=cos`，`local` 可回退。  
4. **演示鉴权**：保留登录页；`demo` / `demo123` 一键进入。  
5. **未实现能力降级**：Batch / Marketing 占位；撤销/点选 SAM/消除替换等顺延。

## 4. 后端完成了什么？

### 4.1 演示鉴权

- `POST /api/auth/login|register`、`POST /logout`、`GET /me`  
- Cookie `image100_demo_session`；固定 DEMO 用户  
- 登录页一键：`demo` / `demo123`

### 4.2 会话与工具兼容

- 创建接受 `current_asset_id` / `asset_id`  
- `GET/POST /sessions` 返回原仓 `SessionDetail` 形状（补 transform/kind 等默认）  
- `POST /sessions/{id}/tools` body `{tool,params}` → `{run,session}`  
- `set_layer_visible` 直写 document（无独立工具）  
- `POST .../selection` 笔刷 → document.selection + 青色 mask 资产  
- `POST .../exports` → 扁平 PNG（非 zip）  
- undo/redo → 501

### 4.3 Agent / 生图 / Run

- `/sessions/{id}/messages*` 转发本仓 Agent；状态映射 `planned→queued` 等  
- `POST /generations` 接受 `ratio`，返回 Run 形状  
- `GET /runs/{id}` 同时覆盖 ToolRun 与 GenerationRun

### 4.4 COS

- `STORAGE_BACKEND=cos|local`（代码与 example **默认 cos**）  
- `cos-python-sdk-v5`；读图统一字节响应，兼容私有桶  
- `GET /api/health` 的 `storage` 探测可写

## 8. 本地复现（速查）

```bash

conda activate image100
pip install -e .
uvicorn app.main:app --reload --host 0.0.0.0 --port 7302

# 终端 3
```
