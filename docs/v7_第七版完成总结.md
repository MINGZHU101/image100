## 1. 第七版要解决什么问题？

v1～v6 始终是「单主图层」叙事。电商场景常要「主体和背景分开调」，v7 补上图层能力：

1. **能拆层**：工具 `split_layers` —— mock 去背得主体，本地填洞得背景。  
2. **能看层**：左侧 **LayerPanel** 列出图层，显隐与选中。  
3. **能叠画**：`CanvasStage` 自下而上叠放多层；透明区棋盘格提示。  
4. **能按层修**：提亮 / 去背 / 翻转 / 局部提亮作用在 `active_layer_id`。  
5. **能导出**：可见层扁平化为一张 PNG。  
6. **Agent 可感知**：上下文列图层；Mock「拆层」→ `split_layers`。

|----|------|

## 4. 后端完成了什么？

### 4.1 能力清单

1. `split_layers`：读 `layer_main`（或单层）→ 主体 PNG + 背景 PNG → 替换为 `layer_background` / `layer_subject`，默认 `active_layer_id=layer_subject`。  
2. 已拆层：直接跳过（`skipped: true`）。  
3. 填洞：优先 OpenCV inpaint（若已装），否则 Pillow blur 兜底。  
4. 修图工具经 `load_target_layer_bytes` / `write_result_asset` 打在当前层。  
5. `PATCH /sessions/{id}/layers`：可见性 + `active_layer_id`。  
6. 导出：`flatten_visible_layers` 自下而上 alpha 合成。

### 4.2 拆层后 document（冻结）

```json
{
  "layers": [
    { "id": "layer_background", "name": "背景", "visible": true, "locked": true, "asset_id": "..." },
    { "id": "layer_subject", "name": "主体", "visible": true, "locked": false, "asset_id": "..." }
  ],
  "active_layer_id": "layer_subject",
  "selection": null
}
```

### 4.3 接口一览（v7 增量）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `.../tools/split_layers` | 拆层（复用 tools 路由） |
| PATCH | `/api/sessions/{id}/layers` | `{ layers?: [{id, visible}], active_layer_id? }` |
| GET | `/api/sessions/{id}/export` | 可见层扁平化 PNG |

### 4.4 关键文件

| 文件 | 一句话 |
|------|--------|
| `edits/split.py` | 去背 + 填洞 + 多层合成 |
| `tools/layers.py` | `SPLIT_LAYERS` 入队执行 |
| `layers.py` | `already_split` / `resolve_target_layer` |
| `services/runs.py` | 按 active 层读写；导出扁平化 |
| `providers/mock.py` | 「拆层」关键词 → `split_layers` |

## 5. 调用关系总图

```text
用户：拆层
  → POST .../tools/split_layers → ARQ
  → Worker：mock 去背 → 填洞 → 两 Asset → 更新 layers
  → SSE completed → 前端 reload

用户：图层面板「隐」主体
  → PATCH .../layers { layers:[{id, visible:false}] }
  → Canvas 只画可见层

用户：选中主体 → 提亮
  → adjust_image 读写 layer_subject
  → 背景不变
```
