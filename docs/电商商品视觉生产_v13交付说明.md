> - `电商商品视觉生产_v12交付说明.md`、`v12_第十二版完成总结.md`

## 2. 本版四大需求

### 2.1 Docker 一键启动

| 项 | 口径 |
|----|------|
| 入口 | 项目根 `docker-compose.yml` |
| 服务 | `postgres` / `redis` / `api` / `worker` / `web` |
| 端口 | 前端 `7301`，API `7302`，PG `7311`，Redis `7312` |
| 存储默认 | **`STORAGE_BACKEND=cos`**（腾讯云）；可改 `local` |
| 构建 | `docker/` 下 backend / frontend Dockerfile + nginx + entrypoint |
| 本机开发 | 可选 `python run.py` 同时起 API + Worker + Vite |

### 2.2 管理端界面与用户端对齐

| 项 | 口径 |
|----|------|
| 色板 | `canvas` / `paper` / `brand` 等与用户端 design token 一致 |
| 共用 | `adminUi`、`AdminPageHeader`、分组侧栏 |
| 范围 | 仪表盘、用户、积分、公告、运营参数、批量发分、管理员、审计、邀请、会话、转盘等页 |

### 2.3 批量进度「0 张」修复

| 项 | 口径 |
|----|------|
| 根因 | `GET /batches`、`GET /batches/{id}` 曾写死 `items: []` |
| 方案 | `ToolRun.params['_batch']` 关联同批多图；列表/详情返回真实 items |
| 导出 | `GET /batches/{id}/export` 打包成功结果 zip |
| 前端 | 按整批 items 判断完成与张数，不再只看第一张 run |

### 2.4 智能客服更智能

| 项 | 口径 |
|----|------|
| 语料 | 扩充使用教程：充值路径、找图、批量下载、转盘、401 等 FAQ |
| 检索 | 口语同义词、更多 top-k、教程更新自动重建索引 |
| 拒答 | 仅拦明显站外话题；「怎么充值」「图片在哪」应能答 |

## 4. 验收清单

1. `docker compose up -d --build` 后 `:7301` 可打开工作台，`:7302/api/health` 正常。  
2. `.env` 填 COS 四项后可上传读图；改 `local` 可回退。  
3. `/admin` 视觉与用户端同系，无旧版 slate/teal 割裂感。  
4. 新建批量任务：进度页显示 N 张明细，完成后可打包下载。  
5. 客服可回答「生成图片在哪里」「怎么充值」；明显闲聊可拒答。  
6. 更新语料后：`docker compose exec api python -m app.rag.build_index`（或依赖 mtime 自动重建）。
