# 电商商品视觉工作台 · 使用教程

> 本文档是工作台内 **AI 智能客服** 的知识库语料，也供用户自行阅读。  
> 产品名称：**电商商品视觉工作台**（工程代号 image100）

---

## 1. 产品是什么

面向中小电商卖家与运营的「自然语言电商修图工作台」：用文字描述生成商品图，在编辑器里改图、导出营销尺寸，并支持批量处理、文案生成、积分会员与幸运大转盘。普通用户入口是工作台；管理员另有「电商商品视觉管理台」。

一句话：上传或生成商品图 → 编辑修图 / Agent 改图 → 导出或批量出图；文案、积分、会员都在站内完成。

## 2. 登录与账号

- 打开站点后进入登录页，可 **注册** 或 **登录**。
- 演示账号：`demo` / `demo123`（登录页有一键按钮）；演示账号积分与日额度不限，但不参与新手礼包，也不适合当作真实充值测试。
- 登录页可切换 **用户登录 | 管理员登录**。管理员默认种子账号见部署说明（一般为 `admin`），登录后进入 `/admin`，不会进入用户工作台。
- **个人中心**可改展示名、密码、上传头像。
- 忘记密码：当前版本请在个人中心「已登录状态下」修改密码；未登录无法自助找回时，请联系站点管理员重置。

## 3. 侧栏入口在哪里（功能地图）

登录后左侧导航（悬停可展开文字），从上到下大致为：

| 入口 | 路径 | 做什么 |
|------|------|--------|
| **创作** | `/create` | 文生图、上传图片、打开历史素材 |
| **文案生成** | `/copywriting` | 根据提示词和/或商品图生成电商文案 |
| **编辑** | `/editor` | 画布修图、Agent 规划、图层与选区工具 |
| **导出** | `/marketing` | 营销尺寸导出 |
| **批量** | `/batch` | 多图同一套流程批量处理，看进度与打包下载 |
| **个人中心** | `/account` | 积分、签到、充值兑换、邀请、安全设置、幸运大转盘入口等 |

**生成图片功能在「创作」页**：填写画面描述，选比例与张数，点生成；完成后进入 **候选图** 页，再选一张进入编辑器。

**已经生成好的图在哪看？**

1. 刚生成完：在创作流程的 **候选图 / 结果页** 里挑选。  
2. 历史素材：回到 **创作** 页，使用「历史素材 / 上传过的图」列表打开。  
3. 进入过编辑器的：可从编辑相关入口打开会话继续改。  
4. 批量结果：在 **批量** 页对应任务里查看，完成后可 **打包下载**。

## 4. 创作：如何生成图片

1. 打开侧栏 **创作**。
2. 在输入框描述你想要的画面（商品、场景、光线、背景等）。
3. 选择比例（如 1:1、4:5、9:16、16:9）与数量（1 / 2 / 4 / 6 等）。
4. 可按需选择文生图模型（如通义万相 2.0 / 3.0，以页面可选为准）。
5. 提交后等待生成；在候选页查看多张结果。
6. 选中一张进入 **编辑** 继续修图，或从「上传已有图片 / 历史素材」直接进编辑器。

当选择生成 **2 张及以上** 时，系统会对提示词做改写与扩写，让多张图在构图、光线或场景侧重点上有所差异，避免完全雷同。

文生图会消耗积分（见「计费」），并占用当日 AI 次数。若提示 API Key 无效 / 401，属于大模型密钥配置问题，请联系管理员检查 `DASHSCOPE_API_KEY`，用户侧可先改用 Mock（若页面提供）或稍后再试。

## 5. 文案生成：怎么用、怎么计费

1. 打开侧栏 **文案生成**（位于「创作」与「编辑」之间）。
2. 输入产品提示词；可选 **上传图片** 或选择已有素材，系统会先看图再写文案。
3. 生成过程分阶段流式展示：分析卖点 / 看图 → 标题 → 正文与标签。
4. 生成结束后可复制使用。

**计费**：每次文案生成成功结束扣 **40 积分**；中途失败不扣费。计入当日 AI 次数。演示账号不扣分。

---

## 6. 编辑器能做什么

- 打开已有会话或从创作进入后，可在画布上调整画面。
- 常见能力（以界面实际按钮为准）：去背景、换背景、调色/提亮、超分放大、扩图、裁剪、翻转、拆层、区域调整、擦除、图层透明度/移动/旋转等。
- **Agent**：用自然语言描述修改目标，系统给出计划，确认后按步骤执行工具。
- 支持撤销 / 重做；可把结果用于导出或继续编辑。

部分云端重度能力（如完整 SAM、rembg 等）可能仍在迭代，以当前界面可用按钮为准。Agent / 部分云端编辑会扣积分并占日额度。

## 7. 导出与批量

### 7.1 导出（营销尺寸）

- 打开侧栏 **导出**（`/marketing`）。
- 针对当前会话/素材导出适合投放的尺寸（如 1:1、4:5、9:16 等，以页面选项为准）。
- 适合主图、详情长图、短视频封面等电商场景。

### 7.2 批量

1. 打开侧栏 **批量**。
2. 选择多张图片（可上传或从历史素材添加，有上限，如最多约 20 张）。
3. 勾选同一套处理步骤（去背、换背景、调色、超分、扩图、投放尺寸等）。
4. 点「开始处理」，进入 **批量进度** 页查看每张状态。
5. 全部完成后可 **打包下载** 成功结果。

若进度页显示「完成」但张数为 0，多为旧任务无明细；请新建批量任务。处理中请保持网络畅通，Worker 异常时任务可能失败，可重试。

## 8. 积分、余额、充值与会员

### 8.1 积分怎么来

- **新手礼包**：个人中心总览页礼物盒图标，一生一次，领取起步积分（默认约 2000）；演示账号不显示礼包。
- **每日签到**：按会员等级给不同积分（青铜较少，钻石较多）。
- **充值 / 兑换**：先在个人中心做 **模拟充值** 把金额充到 **账户余额（元）**，再把余额 **兑换成积分**（默认约 **1 元 = 10 积分**，以运营配置为准）。这就是「怎么充值」的完整路径：个人中心 → 充值/签到相关入口 → 充余额 → 兑换积分。
- **邀请好友**：生成邀请码，好友注册或登录时填写，双方按规则得奖励。
- **幸运大转盘**：个人中心相关入口，按当月规则消耗余额次数抽奖，可能获得积分或会员升级等奖项（以页面说明为准）。

### 8.2 积分怎么花

| 操作 | 大约消耗 |
|------|----------|
| 文生图 | 约 80 分/次（以实际扣费为准） |
| Agent 一轮 | 约 50 分 |
| 文案生成 | **40 分**/次（成功才扣） |
| 部分云端编辑 | 约 60 分 |

积分不足时会提示先充值/兑换；请到个人中心处理。演示账号通常不扣分。

### 8.3 余额和积分有什么区别

- **余额（元）**：充值到账的钱包金额，主要用于兑换积分，以及部分活动（如转盘次数费用，以页面为准）。
- **积分**：消费文生图、Agent、文案等能力时扣除。  
充值不会直接变成「会员等级」；等级看累计消耗积分。

### 8.4 怎么升级到钻石会员

会员等级由 **累计消耗积分** 自动结算，不是单独付费买等级：

| 等级 | 累计消耗约 |
|------|------------|
| 青铜 | 0 起 |
| 白银 | ≥ 500 |
| 黄金 | ≥ 2000 |
| 铂金 | ≥ 5000 |
| **钻石** | **≥ 15000** |

因此：多使用文生图、Agent、文案等会累计消耗；达到约 15000 消耗即可升到钻石。钻石签到奖励与日 AI 额度更高。个人中心总览会显示当前等级与距下一档还差多少。

### 8.5 日额度与并发

不同会员每日 AI 次数上限不同（青铜较低，钻石较高）；同时进行的任务数也有并发上限。超额会提示稍后再试，次日或升级后额度会变化。

## 9. 幸运大转盘

- 入口一般在 **个人中心**（或活动入口，以界面为准）。
- 按自然月重置次数与费用阶梯；大奖可能触发全站弹幕。
- 奖池含积分、会员升一级等（具体扇区以当月配置为准；下月配置由管理员在管理台调整）。
- 演示/活动规则以页面提示为准，抽奖前请确认余额是否足够支付当次费用。

## 11. 管理端（仅管理员）

管理员登录后进入 **电商商品视觉管理台**（`/admin`）：用户管理、调积分/余额、冻结、公告、运营参数、批量发分、幸运大转盘配置、操作日志等。普通用户无法使用管理台。

## 12. 常见问题 FAQ

**问：生成图片在哪里？生成的图去哪找？**  
答：在左侧打开 **创作** 生成；生成后在候选结果里查看。之后可在创作页的 **历史素材** 中再次打开，或进入过编辑器的会话继续查看。批量任务结果在 **批量** 进度页，可打包下载。

**问：怎么充值？如何买积分？**  
答：打开 **个人中心** → 找到充值/签到相关入口 → 先 **模拟充值** 到账户余额 → 再把余额 **兑换成积分**（默认约 1 元 = 10 积分）。充值到的是余额，兑换后才是可消费的积分。

**问：我在哪个位置使用生成图片功能？**  
答：登录后点左侧 **创作**，在描述框填写提示词，选比例与张数后生成。

**问：文案生成是怎么计费的？**  
答：每次成功生成扣 40 积分，失败不扣；计入当日 AI 次数。

**问：我怎么才能升级到钻石会员？**  
答：通过使用功能累计消耗积分达到约 15000，系统自动升为钻石，无需单独购买等级。

**问：多张生图为什么看起来不一样？**  
答：选 2 张及以上时，系统会改写扩写提示词再分别生成，减少雷同。

**问：新手积分怎么领？**  
答：个人中心总览点礼物盒，按提示「马上领取」。演示账号一般没有礼包。

**问：签到在哪里？**  
答：个人中心的签到/充值相关区域，每日可签到领取积分，等级越高通常奖励越多。

**问：邀请好友怎么玩？**  
答：个人中心生成邀请码，发给好友；好友注册或登录时填写，双方按规则获得奖励。

**问：批量处理怎么用？结果如何下载？**  
答：侧栏进 **批量** → 选图 → 勾选步骤 → 开始处理 → 在进度页等待完成 → 点 **打包下载**。

**问：导出营销图在哪？**  
答：侧栏 **导出**（营销尺寸），按页面比例导出适合电商投放的尺寸。

**问：Agent 是什么？怎么用？**  
答：在 **编辑器** 里用自然语言描述你想怎么改图，确认计划后系统按步骤调用工具执行。会消耗积分与日额度。

**问：积分不够怎么办？**  
答：去个人中心签到、领礼包（若仍可领）、充值兑换积分，或通过邀请/转盘等活动获取。

**问：生图失败 / 提示 Invalid API-key / 401？**  
答：多为服务端大模型密钥未配置或无效。请联系管理员检查配置；你可稍后再试，或改用页面提供的 Mock（若有）。

**问：演示账号和管理员账号是什么？**  
答：演示用户常见为 `demo` / `demo123`；管理员需在登录页切换「管理员登录」，默认种子见部署说明（如 `admin`）。管理员进 `/admin`，不是用户工作台。

**问：可以改密码、换头像吗？**  
答：可以。在 **个人中心** 的安全/资料设置中修改密码、展示名，并上传头像。

**问：客服能回答什么？**  
答：本站使用方式：入口位置、生图与找图、文案计费、充值兑换、会员升级、批量导出、转盘与积分规则等。不能代替人工处理退款纠纷或回答与本站无关的话题。
