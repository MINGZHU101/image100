## 3. 规则与行为摘要

### 3.1 部署

- 虚拟机目录执行：`docker compose up -d --build`。  
- 默认 COS；本地盘回退设 `STORAGE_BACKEND=local`。  
- API 启动 entrypoint：等库 → `alembic upgrade head` → uvicorn；Worker 跳过迁移。  

### 3.2 批量

- 创建时对每张图建会话并入队流水线**第一个**工具；在各 `ToolRun.params['_batch']` 写入 `leader_id` / `run_ids` / `source_asset_ids`。  
- 历史列表只展示「队长」任务，避免编辑器单次工具刷屏。  
- 修复前旧任务无元数据，张数仍可能为 0，需**新建任务**验证。  

### 3.3 客服

- 知识库即 `docs/电商商品视觉工作台使用教程.md`。  
- 明显站外话题拒答；站内口语（充值、图片在哪）应检索作答。  
- 语料更新后：依赖文件 mtime 自动 `rebuild_index`，或手动 `python -m app.rag.build_index`。

## 4. 验收提示

1. Compose 起全套 → `http://<IP>:7301/` 登录 `demo` / `demo123`。  
2. 管理端 `admin` / `admin123456` → 页面风格与用户端一致。  
3. 批量选多张 → 进度页显示 N 张 → 打包下载。  
4. 客服问「怎么充值」「生成图片在哪里」应给出入口步骤，而非一律拒答。  
5. `.env` 配齐 COS 与可选 `DASHSCOPE_API_KEY`。
