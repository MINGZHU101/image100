## 1. 第六版要解决什么问题？

v3～v5 已能「整图修 / 说话修 / 文生图进编辑器」，但改亮度仍是整图一把梭。v6 补上选区能力：

1. **能框选**：工具栏矩形选区、笔刷选区、清除选区。  
2. **能看见选区**：Konva 半透明 overlay，坐标相对画布 0～1。  
3. **能落库**：`PATCH /api/sessions/{id}/selection` 写入 `document.selection`。  
4. **能局部改**：新工具 `adjust_region` —— 整图调色后按掩膜合成，选区外像素不变。  
5. **Agent 可感知**：上下文含「选区：有/无」；Mock「局部提亮」→ `adjust_region`。

验收口径（Definition of Done）：

| 项 | 结果 |
|----|------|
| `document.selection` 形状（rect / brush） | 已定 |
| `PATCH /api/sessions/{id}/selection` | 已通 |

| Registry 注册 `adjust_region` | 已通 |
| 无选区调用 → 400「请先框选…」 | 已通 |

| 前端选区模式 + overlay + 局部提亮 | 已通 |

**明确未做**：AI 局部消除/替换、SAM、羽化 UI、图层、revision 乐观锁、后端 overlay PNG。

## 4. 后端完成了什么？

### 4.1 能力清单

1. 选区写入会话 JSONB：`rect` 或 `brush`（笔画列表 + `brush_radius`）。  
2. `edits/mask.py`：归一化坐标 → `L` 掩膜；`apply_masked` 合成（轻微 GaussianBlur）。  
3. `adjust_region`：读选区 → 整图 `adjust_image` → 掩膜合成 → 写回主图层 → **清空选区**。  
4. 入队前无选区直接 400；Worker 内再次校验（防竞态清空）。  
5. Agent 上下文：`选区：有（rect|brush）` / `选区：无`。

### 4.2 选区 JSON（冻结）

```json
{ "type": "rect", "rect": { "x": 0.2, "y": 0.3, "width": 0.4, "height": 0.35 }, "feather": 0 }
```

```json
{
  "type": "brush",
  "strokes": [[[0.12, 0.4], [0.18, 0.42]]],
  "brush_radius": 0.03,
  "feather": 0
}
```

### 4.3 接口一览（v6 增量）

| 方法 | 路径 | 说明 |
|------|------|------|
| PATCH | `/api/sessions/{id}/selection` | body `{ "selection": {...} \| null }` |
| POST | `/api/sessions/{id}/tools/adjust_region` | 局部提亮（复用既有 tools 路由） |
| GET | `/api/tools` | 列表含「局部提亮」 |

其余会话 / 工具 / Agent / 生图接口不变。

### 4.4 行为约定（已确认默认）

| 项 | 约定 |
|----|------|
| 矩形 | 每次画完替换选区 |
| 笔刷 | 同模式多笔追加并集；换工具/清除才重置 |
| 同步 | 抬笔 PATCH；点局部提亮前再 sync |
| 成功后 | 自动清空 `document.selection` |
| 羽化 | 无 UI；合成侧 blur≈1.2 |

## 5. 后端关键文件详解

### 5.1 `edits/mask.py`【新】

| 函数 | 职责 |
|------|------|
| `rasterize_rect` | 归一化矩形 → 掩膜 |
| `rasterize_strokes` | 闭合填涂 + 线宽兜底 |
| `mask_from_selection` | 按 type 分派 |
| `apply_masked` | 选区内用 edited，区外保留 source |

### 5.2 `tools/region.py`【新】

`ADJUST_REGION`：`ui_exposed` / `agent_exposed` 均为 True；params 与整图提亮同（brightness 默认 +0.2）。

### 5.3 `services/sessions.py`【改】

`update_selection` / `clear_selection`；JSONB `flag_modified`。

### 5.4 Agent【改】

- `prompts.py`：有选区且要局部 → 优先 `adjust_region`。  
- `mock.py`：含「局部/选区/…」+「提亮」且上下文「选区：有」→ `adjust_region`；无选区则中文提示。  
- `_canvas_context`：追加选区摘要。

## 6. 调用关系总图

```text
用户：矩形/笔刷 → 抬笔
  → PATCH /api/sessions/{id}/selection
  → document.selection 落库

用户：局部提亮
  →（前端再 sync）POST .../tools/adjust_region
  → tool_runs queued → ARQ
  → Worker：mask → adjust → apply_masked → 写 asset
  → clear selection → SSE completed
  → 前端 reloadSession → 画布更新、选区清空
```
