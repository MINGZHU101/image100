## 1. 第五版要解决什么问题？

v4 已能「说话修图」，但素材仍依赖上传。v5 补上第二条入口：

1. **能创作**：落地页进 `/create`，输入商品图描述。  
2. **能切换生图方式**：界面 **Mock / 真实生图** 双按钮（对齐 v4 规划器演示体验）。  
3. **不堵 API**：`POST /api/generations` 立即返回 `generation_id`，Worker 执行生图。  
4. **能看见候选**：完成后展示资产网格，点选创建会话进编辑器。  
5. **精修复用**：编辑器内仍用 v3 工具栏 + v4 Agent，不重写像素链路。

## 4. 后端完成了什么？

### 4.1 能力清单

1. `generation_runs` 记录 prompt、params、provider、进度、`result_asset_ids`。  
2. Mock：Pillow 按 prompt 哈希生成稳定占位图。  
3. DashScope：原生 `multimodal-generation/generation`（兼容模式 `/images/generations` 对本 Key 返回 404，已弃用该路径）。  
4. Worker `execute_generation`：调 Provider → 写 `assets` → SSE progress/completed。  
5. `provider-options` 供前端双按钮；无 Key 时 dashscope 不可用。

### 4.2 环境变量（v5）

| 变量 | 含义 | 示例 |
|------|------|------|
| `IMAGE_PROVIDER` | 默认生图方式 | `dashscope` |
| `TEXT_TO_IMAGE_MODEL` | 模型名 | `qwen-image-3.0-pro` |
| `DASHSCOPE_IMAGE_URL` | 原生文生图 URL | `.../multimodal-generation/generation` |
| `DASHSCOPE_API_KEY` | 与 v4 共用 | 系统环境变量 |

> 规划器仍用 `DASHSCOPE_BASE_URL`（compatible-mode）；生图与规划 **端点分离**。

### 4.3 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/generations/provider-options` | Mock/真实是否可用 |
| POST | `/api/generations` | 入队，返回 `generation_id` |
| GET | `/api/generations/{id}` | 状态与候选 asset_ids |
| GET | `/api/events/{id}` | SSE（工具或生图） |

进编辑器仍用：`POST /api/sessions`、`GET /api/assets/{id}/file`。

### 4.4 默认参数（锁定）

- 尺寸：`1024×1024`  
- 张数：默认 2，上限 4  
- 一律 ARQ 入队

## 5. 后端关键文件详解

### 5.1 `providers/image.py`【新】

| 项 | 说明 |
|----|------|
| **一句话** | ImageProvider：prompt → PNG 字节列表。 |
| `MockImageProvider` | 色块+圆，构图由哈希决定，稳定可演示 |
| `DashscopeImageProvider` | POST 原生多模态；解析 `output.choices[].message.content[].image` URL 后下载 |
| `get_image_provider` | `mock` / `dashscope` 工厂 |

### 5.2 `models/generation_run.py` + 迁移

字段：`prompt`、`params`、`image_provider`、`status`、`progress`、`result_asset_ids`、`error`、`finished_at`。

### 5.3 `services/generation.py`

- `create_generation`：落库 queued → enqueue  
- `execute_generation`：running → generate → 每张写 Asset → succeeded + SSE  
- `provider_options`：前端按钮数据源  

### 5.4 `tasks/generation.py` / `queue.py` / `worker.py`

ARQ 函数名 `execute_generation`，`_job_id=gen-{uuid}`。

### 5.5 `routers/generations.py` / `events.py`

薄 HTTP；SSE 先查 `ToolRun`，再查 `GenerationRun`，终态回放 `asset_ids`。

### 5.6 `config.py`【改】

新增 `image_provider`、`text_to_image_model`、`dashscope_image_url`。

## 6. 调用关系总图

```text
CreatePage (Mock|真实)
  → POST /api/generations
       → generation_runs(queued) → ARQ
  → Worker execute_generation
       → ImageProvider.generate
       → assets + storage
       → SSE progress/completed
  → 候选网格 /api/assets/{id}/file
  → POST /api/sessions → /editor/:id
  → 工具栏 / Agent（v3/v4）
```
